# Steklo AirPlay

Делает каждый телевизор с лаунчером «Стекло» колонкой AirPlay 2 с названием его комнаты.

- iPhone, iPad и Mac видят «Кухню», «Прихожую», «Спальную Юлии» в списке AirPlay. Их можно объединять между собой и с HomePod, ими управляют из Пункта управления, приложения «Дом» и Siri.
- Звук, название, исполнитель и обложка уходят на телевизор. «Стекло» показывает обложку справа на главном экране, а кнопки под ней управляют iPhone.
- Колонка появляется, только пока телевизор включён и подключён к дополнению.

Внутри работает [shairport-sync](https://github.com/mikebrady/shairport-sync) 5.6.2 в режиме AirPlay 2 с одним общим `nqptp` для всех комнат.

## Настройки

| Параметр | По умолчанию | Что делает |
|---|---|---|
| `bridge_port` | 7700 | Порт, к которому подключаются телевизоры (они находят его сами по mDNS) |
| `first_airplay_port` | 7001 | Первый порт колонок AirPlay; следующие комнаты берут 7002, 7003… |
| `latency_offset_ms` | −150 | Насколько раньше отдавать звук, чтобы телевизор играл в такт с другими колонками AirPlay |

Если телевизор отстаёт от HomePod в общей группе, уменьшите `latency_offset_ms`, например до −250.
