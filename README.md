# Стекло — дополнения Home Assistant

## Steklo AirPlay

Делает телевизоры с лаунчером «Стекло» колонками AirPlay 2. Подробности — в [steklo_airplay/DOCS.md](steklo_airplay/DOCS.md).

Установка: «Настройки → Дополнения → Магазин дополнений → ⋮ → Репозитории», добавить `https://github.com/cumonmycode/steklo-airplay`, затем установить «Steklo AirPlay».
